# אוגדן הנחיות להיתר, עיריית אשדוד

אפליקציית עבודה לעורכי בקשה להיתר בנייה, מבוססת על "אוגדן הנחיות מידע להיתר לעורכי בקשה", נוסח 01/01/2025.
כתובת: https://ogdan-gh.vercel.app

## מה יש בה
- **9 פרקים** (רישוי, פיקוח, כבישים, ניקוז, נטיעות, חשמל, תברואה, מים, סביבה), עם 81 דרישות כרשימות סימון שנשמרות בדפדפן.
- **תיק בקשה**: נתוני הפרויקט מוזנים פעם אחת ומזינים את כל המחשבונים. דוח מסכם להדפסה עם בדיקות אוטומטיות (חלחול 15%, שטח ירוק, מערכת אשפה כפולה, גנרטור).
- **6 מחשבונים**: חניה (שימוש מעורב, תקן אשדוד או ארצי), ניקוז (נוסחת הרציונל), שטח ירוק, אשפה, מים, אגרות. לכל אחד ויזואליזציה מונפשת (תכנית מגרש בקנה מידה, רשת חניות, מכלי אשפה, פסי הרכב עם קו סף), "שלבי החישוב" שקופים ומגבלות כתובות.
- **ספר טלפונים** של 28 אנשי קשר, עם חיפוש וסינון.
- **חיפוש בכל האוגדן** (Ctrl+K או /).
- **שיתוף**: העתקת קישור מכפתור A&I כוללת את תיק הבקשה והסימונים.
- **התקנה כאפליקציה** (PWA), עבודה לא מקוונת, מצב כהה, הפחתת תנועה, RTL מלא, נייד בלי גלילה אופקית.

## הרצה
```bash
npm install
npm run dev        # פיתוח
npm test           # בדיקות יחידה לנוסחאות
npm run build
npm run e2e        # Playwright מול vite preview, צילומי מסך ב-e2e/shots
```

## מבנה
```
src/data/permitData.ts      מקור הנתונים היחיד: פרקים, דרישות, אנשי קשר, בנקים, מסלולים
src/logic/calculators.ts    נוסחאות טהורות + שלבי חישוב, עם calculators.test.ts
src/logic/search.ts         אינדקס חיפוש שנגזר מהנתונים
src/state/store.ts          תיק הבקשה והסימונים, localStorage, חיווי "נשמר", קידוד מצב לקישור
src/state/router.ts         ניתוב hash: #/chapter/:id, #/tool/:id, #/tools, #/contacts, #/project
src/design/app.css          אסימוני עיצוב ("גיליון שרטוט"), רכיבים, מובייל, הדפסה
src/components/             סרגל עליון, כפתור A&I, חיפוש, מחשבונים, רכיבי בסיס
src/pages/                  בית, פרק, כלים, טלפונים, תיק בקשה
public/                     manifest, sw.js, אייקונים
e2e/                        run.mjs (בדיקות), icons.mjs (יצירת אייקונים)
```

## החלטות
- **ניתוב hash** ולא היסטוריה: עובד בכל אחסון סטטי בלי הגדרות rewrite.
- **בלי שרת**: אין מידע אישי לשמור מעבר לדפדפן. שיתוף נעשה בקישור.
- **בלי ספריית רכיבים**: מערכת עיצוב אחת בקובץ CSS, כפתורים מרובעים, לבן-אפור-שחור עם צבע רמזור לסטטוס בלבד, סט אייקונים קווי מינימלי לתכנים.
- **מודל תלת־ממדי ב-CSS** ולא Three.js: 9 קומות = 9 פרקים, המילוי בכל קומה הוא ההתקדמות בפרק. קל, נגיש, ומוצג גם בהפחתת תנועה.

## הסתייגות
החישובים הם אומדן לפי מקדמי האוגדן ותקנים מקובלים. הם אינם מחליפים את בדיקת מחלקת הרישוי, היועצים ואיש המקצוע החותם.
